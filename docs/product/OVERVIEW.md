# Nori — Product Overview

Habit tracker + virtual pet game (Flutter), UFM Desarrollo de Productos de Software project.
Two devs: valevasqc (Valeria), jimenaestradad (Jimena).

## The idea

Closer to **Club Penguin Puffles** than a traditional RPG or a literal Tamagotchi: pets grow
from *real-life* habit consistency, not from feeding/care actions alone. Three layers:

- **Habit tracker** — tracks real-world behavior.
- **Virtual pet** — turns consistency into progression, care, collection, rewards.
- **Social/accountability** — friends, competition (vision, not MVP).

```
complete habits → earn XP + coins → progress & care for pet(s) →
level / evolve / collect / customize pets → stay motivated
```

For actual feature mechanics (habit types, XP/streaks, pet care, economy, social, MVP
boundary, competitor references) see [FEATURES.md](FEATURES.md) — that's the source of truth
for scope, not this file. For what's still undecided, see [OPEN_DECISIONS.md](OPEN_DECISIONS.md).

## Platform

Mobile, **Android only**. iOS is out of scope — Apple requires a paid developer license, not
viable for a university project. Desktop is also out of scope (would be worth doing outside
the university-project timeline, not now). Don't build or maintain iOS/desktop-specific code.
